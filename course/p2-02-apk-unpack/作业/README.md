# 2.2 作业：重打包——塞个文件、对齐、重签

## 题干

重打包的完整一套：**解包 → 改点东西 → 重新对齐 → 重新签名 → 装得上**。这一课把"改点东西"简化成往包里塞一个空 `change.txt`，重点练**对齐 + 重签**这两步（改了包，原签名就失效了，必须重签）。

你要交一个重打包好的 APK，满足三项：包里有 `change.txt`、已 4 字节对齐、签名有效。

## 材料

面板上点 **⬇ 下载靶子 APK** 拿到 `app-unsigned.apk`。

## 怎么交

在塔里点这个节点 → **✍ 做作业** → **选文件**上传你重打包好的 `aligned.apk` → **▶ 上传并批改**。
批改器在你本机跑三项**工具级判定**（都是确定的，不会误判）：

1. APK 里有 `change.txt`（`unzip -l` 能看到）。
2. 已 `zipalign` 对齐（`zipalign -c 4` 通过）。
3. 签名有效（`apksigner verify` 通过——证明你重签过了）。

三项全绿 → 点亮。哪项没过它会告诉你补哪步。
