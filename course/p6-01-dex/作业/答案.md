> 先自己动手，卡住了再看。

> `dexflag-demo.apk` 是个能玩的 Unity 爬塔（点 [攻击]/[重击] 爬 5 层塔）。游戏主体在 C#，flag
> 却在 Java 层的插件类 `com.course.dexflag.FlagHolder` 里——把塔玩通关也拿不到 flag，得反编译 dex。

### 一、一步步操作

1. **提 dex**：APK 是 zip，解出 `classes.dex`：
   ```bash
   unzip dexflag-demo.apk classes.dex
   ```

2. **jadx 反编译**：
   ```bash
   ~/.reverse-tools/jadx-1.5.1/bin/jadx --no-res --no-debug-info -d out classes.dex
   ```

3. **读自定义类**：反编译结果里大头是 `com/unity3d/player/*`（Unity 启动器）、`com/google/*` 等 SDK；要读的在应用自己的包 `com/course/dexflag/`：
   ```bash
   cat out/sources/com/course/dexflag/FlagHolder.java
   ```
   读 `reward()` 的拼法（分段数组 + 拼接），照着算出成品 flag。`strings classes.dex | grep urev` 只能看到碎片，成品得照拼法算。

4. **交答案**：
   ```bash
   check.exe FLAG{...}
   ```

### 二、知识点解析

- APK 解 zip 取 `classes*.dex`，jadx headless 反编译（用 `jadx.bat`/`jadx` 启动脚本，走无头模式）。
- 对反编译结果分类：Unity 启动器 / 第三方 SDK / **应用自己的包**——要读的在最后一类。
- 没混淆时 jadx 反编译回可读 Java，读逻辑 / `grep` 字符串 / 照运行时拼法算出 flag。
