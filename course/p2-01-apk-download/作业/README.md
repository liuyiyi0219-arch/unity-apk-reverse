# 2.1 作业：把靶子的签名指纹当 flag

## 题干

验真的核心是**签名**——同一个开发者签的包，签名证书指纹一致；被重打包/重签的赝品，指纹就变了。这一课的作业：**取靶子 APK 签名证书的 SHA1 指纹，那串指纹就是你的 flag。**

## 材料

| 文件 | 是什么 |
|---|---|
| 靶子 APK | 1.2 装的那个包，签名证书的 SHA1 指纹就是 flag |
| `材料/target-cert.der` | 导出好的靶子签名证书（可直接读指纹） |

## 怎么交

在塔里点这个节点 → **✍ 做作业** → 把拼好的 flag 填进去 → **▶ 运行批改**。
批改器会从 `材料/target-cert.der` 自己算一遍 SHA1 和你交的比，对了就点亮。
