### 〇、靶包是个能玩的小游戏

`il2cppflag.apk` 装上是一个**爬塔回合制小游戏**（uGUI 按钮 `[攻击]`/`[重击]`，打穿 5 层 Boss 通关）。flag 不在界面上——它是游戏里 `Vault31`（继承 `ClearCodeVault` 的"开发者内测通关码金库"）的一个明文 string 字段，`GetClearCode()` 返回它。TowerGame 通关时只把这个码的**长度**打进 logcat、**绝不显示到 UI**，所以把塔玩通关也拿不到 flag——只能 dump 骨架、去 metadata 的字符串字面量表里挖。

### 一、一步步操作

1. 解包 `il2cppflag.apk`（就是个 zip），取两样：
   - `assets/bin/Data/Managed/Metadata/global-metadata.dat`
   - `lib/arm64-v8a/libil2cpp.so`
2. 用 **Il2CppDumper**（lxraa fork，见 0.1）出骨架：
   ```bash
   Il2CppDumper.exe libil2cpp.so global-metadata.dat out/
   # out/dump.cs 里搜 Vault31，能看到这个类（继承 ClearCodeVault）和它的 string 字段 clearCode
   ```
   骨架里 `Vault31` 长这样：
   ```csharp
   public class Vault31 : ClearCodeVault
   {
       private readonly string clearCode;         // 明文字面量 = flag
       public override string GetClearCode() { }  // 返回 clearCode
   }
   ```
3. 那个 string 字段的**值**就是 flag。因为它是明文字符串字面量，Il2CppDumper 会把它导进 **`out/stringliteral.json`**（搜 `FLAG{` 一眼看到）；最省事的一条路是直接 `strings global-metadata.dat | grep FLAG`。

### 二、知识点解析

- **出骨架的原理**：Unity 用 IL2CPP 打包后，C# 编成 native，但类型/字段/方法的结构信息都在 `global-metadata.dat` 里，用 Il2CppDumper 就能把骨架 `dump.cs` 还原出来。这就是为什么骨架里能看到 `Vault31 : ClearCodeVault`、看到 `GetClearCode` 这个方法名和 `clearCode` 这个字段名——名字都明文存在 metadata 里。
- **字段值从哪来**：IL2CPP 里字符串字面量（`"FLAG{...}"` 这种）是**明文**存进 `global-metadata.dat` 的字符串字面量表的——所以 `strings global-metadata.dat | grep FLAG` 直接就能捞，Il2CppDumper 也会把整张表导成 `stringliteral.json`。dump.cs 出骨架让你看到它属于哪个类哪个字段；metadata 里的明文串给你字段的值。两样配起来，就是"读结构 + 取值"。
- **为什么玩游戏拿不到**：游戏只用这个码的长度、从不把明文显示到 UI，明文只在 `GetClearCode()` 跑完那一瞬活在内存里。**这一章的 flag 之所以能静态直接捞，是因为它是明文字面量**——到 3.2（藏进伪 C 的 XXTEA 密文）、3.4（运行时 AES 拼出），同样"不显示到 UI"的 flag 就得读逻辑或 hook 才能拿了。
- **先看 magic**：先认一眼 `global-metadata.dat` 开头是不是 `AF 1B B1 FA`（明文 magic）——是就能直接 dump；不是就说明 metadata 被加密了（那是 3.7/3.8 的事）。本课靶包是明文的。
