# 3.1 作业：出骨架，从 IL2CPP 靶包里挖出 string 字段的值

## 题干

点面板上的 **⬇ 下载材料**，拿到 `il2cppflag.apk`。装上是个能点着玩的**爬塔小游戏**（`[攻击]`/`[重击]` 打穿 5 层 Boss 通关），但 flag 不在界面上——它是游戏里 `Vault31`（"开发者内测通关码金库"）的一个 **string 成员变量，值就是 flag**；游戏通关也只把它的长度打进 logcat、绝不显示。用出骨架的办法把这个值挖出来。

## 材料

| 文件 | 是什么 |
|---|---|
| `il2cppflag.apk` | Unity IL2CPP 靶包，装上是个能玩的爬塔小游戏。flag 是游戏里 `Vault31` 类的一个明文 string 字段（`GetClearCode` 返回它），值就是 flag——玩通关也不显示，得 dump 出骨架去 metadata 里挖 |

## 怎么交

塔里点这个节点 → **✍ 做作业** → 把挖出来的 flag 填进去 → **▶ 运行批改**。
