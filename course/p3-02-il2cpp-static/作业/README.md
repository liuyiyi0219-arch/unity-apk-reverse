# 3.2 作业：按 RVA 读伪 C，解出藏在里面的 flag

## 题干

点面板上的 **⬇ 下载材料**，拿到 `il2cppflag32.apk`。这一课的 flag 不是明文字符串（`strings` 抠不到它），而是**藏在一个方法的逻辑里**——你得读懂那段代码才能把它还原出来。目标：解出这个 flag。

## 材料

| 文件 | 是什么 |
|---|---|
| `il2cppflag32.apk` | Unity IL2CPP 靶包，装上是个能玩的爬塔小游戏（`[攻击]`/`[重击]` 打穿 5 层 Boss 通关）。flag 藏在游戏里 `RewardVault.GetClearCode`（开发者内测通关码金库）的伪 C 逻辑里——玩通关也不显示，必须逆向 |

## 怎么交

塔里点这个节点 → **✍ 做作业** → 把解出来的 flag 填进去 → **▶ 运行批改**。
