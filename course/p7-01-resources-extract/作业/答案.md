### 一、一步步操作（二选一）

#### A · AssetStudioMod（GUI 或 CLI）

- GUI：把 `rewardpack` 拖进 AssetStudioMod → 左边选中那张 `Texture2D` → 右键 Export。
- CLI：
  ```bash
  AssetStudioModCLI rewardpack -t tex2d -o out
  ```
  导出的 PNG 在 `out/` 下。

#### B · UnityPy（Python）

```python
import UnityPy
env = UnityPy.load("rewardpack")
for obj in env.objects:
    if obj.type.name in ("Texture2D", "Sprite"):
        data = obj.read()
        data.image.save(f"{data.m_Name}.png")
```

导出后打开 PNG，读图上那行 `FLAG{...}`，交给批改器。

### 二、知识点解析

- 认出标准 `UnityFS` AssetBundle（这里是爬塔的通关奖励包），用 **AssetStudioMod**（AssetStudio 的活跃 fork，原版停维护）或 **UnityPy** 一键 / 脚本化导出。
- 把奖励横幅 `Texture2D` 导成 PNG——没加密时资源提取就是"丢进去、点导出、读"。
- flag 藏在图片像素里（不是文件字符串）：提取工具能把图还原出来，`strings` 不行。
