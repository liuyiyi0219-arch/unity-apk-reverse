### 一、一步步操作

本课只做离线扒包 + 装真机，五样必需装齐即过（不用 .NET/ilspycmd，那是本课反编译 C# 的活）。

**必需项**

1. **装 adb**：把游戏装到真机、连设备，见 0.0。
2. **装 Python 3**：解包 / 脚本（3.1 grep、4.1 XOR 都靠它）。`winget install Python.Python.3.13`。
3. **装 UnityPy**：从 AssetBundle 导资源（7.1）。`pip install -U UnityPy`，装完 `python -c "import UnityPy"` 不报错。
4. **装 Java (JDK)**：jadx 是 Java 写的，跑它要 Java。`winget install EclipseAdoptium.Temurin.21.JDK`。
5. **装 jadx**：DEX 反编译（6.1）。下 [jadx](https://github.com/skylot/jadx) 解压，把 `bin/` 加 PATH。

**建议项**

6. **工具目录 `REVERSE_TOOLS`**：把下载的工具放一处、设环境变量指向它（可选，更顺手）。

### 二、知识点解析

- **为什么 jadx 要 Java**：jadx 是 Java 写的（jar/bat 启动都调 `java`），所以先有 Java 才能跑 jadx——这也是本课把 Java 设为必需的唯一原因。
- **UnityPy 是 python 模块不是命令**：它靠 `pip install` 进 python，验证要用 `python -c "import UnityPy"`，不是敲 `unitypy`。
- **为什么这五样都设必需**：本课 8 章每章都直接用到其中之一——adb 装游戏到真机、python 跑解包/脚本、UnityPy 导资源、java+jadx 反编译 DEX。缺一样就有一章做不了，所以都拦。（本课用不到 .NET/ilspycmd。）
- **唯一的建议项 `REVERSE_TOOLS`**：把散落的免安装工具集中到一个目录、用环境变量指过去，后面脚本能稳定找到，不用写死路径。缺了不拦，纯为顺手。
