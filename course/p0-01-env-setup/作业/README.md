# 0.1 作业：把工具链装好

## 题干

这一课的作业是**把逆向工具链备齐**。批改器探你本机 PATH 上的工具，必需项全绿就过；建议项缺了只提醒、不拦。

你要备齐的清单：

**必需（决定过不过）**
- **Java**
- **adb**（见 0.0）
- **C# 反编译器**

**建议（配上更顺手）**
- **go**
- **python**
- **apktool、jadx**
- **工具目录 `REVERSE_TOOLS`**

## 怎么交

塔里点节点 → **✍ 做作业** → **▶ 运行环境检查**。必需项全绿 → 点亮过关。
清单里 ✘ 的必需项会写怎么装，配好再点一次。
