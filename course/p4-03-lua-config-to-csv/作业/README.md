# 4.3 作业：还原武器配表，从数据里取出 flag

## 题干

材料是爬塔游戏的**武器策划配表** lua（**30 把武器**，keyed、带注解）。flag 不在文件里明摆着——它是**从你还原出的表里算出来的**，算对的前提是你真的把表还原对了。把配表还原成策划表，再按下面的口径算出 flag：

- **X** = `Atk` 最高的那把武器的 `Name`（小写）。
- **N** = 全表 `Price` 之和。

拼成：

```
FLAG{urev-4.3-<X>-<N>}
```

## 材料

下载 `weapon-config-kit.zip`，里面 `weapon.lua` 是爬塔的武器策划配表（keyed、带注解，**30 把武器**）。

## 怎么交

```bash
check.exe FLAG{...}
```

对了它吐 flag 🚩；错了会指出常见坑（列名没对齐 / 漏了行 / 把主键当 1..n）。
