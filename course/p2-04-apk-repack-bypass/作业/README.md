# 2.4 作业：绕过签名校验，让它吐 flag

## 题干

2.3 你读懂了签名校验怎么做。这一课**动手绕过它**：`材料/sigpatch-challenge.apk` 里硬编码了一个"期望签名"，它和这个包的真实签名**故意对不上**——开箱跑一定是"签名校验失败"。你要 **patch 这个包让校验通过**，通过后它会把 flag 打到 logcat / 屏幕上。

## 材料

面板上点 **⬇ 下载材料**，拿到 `sigpatch-challenge.apk`。

## 怎么交

塔里点这个节点 → **✍ 做作业** → 把跑出来的 flag 填进去 → **▶ 运行批改**。
