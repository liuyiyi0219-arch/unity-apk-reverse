# 0.2 作业：把 Frida 调通

## 题干

这一课的作业是**让 Frida 真的连上设备**。批改器探你 host 端的 frida 和设备端的 frida-server。

你要调通的清单：

**必需（决定过不过）**
- **host 端 frida** 能出版本
- **设备端 frida-server 在跑**

**建议**
- **`frida-ps -U` 能枚举进程**

## 怎么交

塔里点节点 → **✍ 做作业** → **▶ 运行环境检查**。必需项全绿 → 点亮过关。
设备端 frida-server 起法、Windows 下的连接通道，见本章讲义。
