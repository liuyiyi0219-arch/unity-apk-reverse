### 一、一步步操作

1. **认每个 blob 的形态**——看头几字节的 magic、看可读性、看熵，对照下表：

   | 形态 | 长相 | 这一课能读吗 |
   |---|---|---|
   | `plaintext` 明文源码 | 直接可读的文本 | 能（但**里面的 flag 是诱饵**） |
   | `luac` 原生 Lua 字节码 | magic `1B 4C 75 61`（`\x1bLua`） | 不能（要反编译，4.2） |
   | `luajit` LuaJIT 字节码 | magic `1B 4C 4A`（`\x1bLJ`） | 不能（ljd，4.2） |
   | `xor` 单字节 XOR 加密 | 乱码，但对某个 key 爆破能解出源码 | **能——真 flag 在这里** |
   | `xxtea` 分组加密 | 乱码、**高熵**，单字节 XOR 怎么爆都解不出 | 不能（找 key，4.8） |

   - `\x1bLua` = 原生 luac、`\x1bLJ` = LuaJIT（正文第 3 步那条分叉），靠 magic 一眼分；字节码这课读不了。
   - 直接可读 = 明文（里面的 flag 是诱饵）。
   - 都不是 magic、又不可读 → 加密。再分两种：**单字节 XOR**（爆破 0–255 能解出 Lua）；**分组加密 XXTEA**（熵接近 8 bit、单字节爆破怎么都解不出，这课解不了 → 4.8）。

2. **锁定那个单字节 XOR 的 blob**（不是明文、无 magic、也不是高熵 XXTEA），**爆破它的 key**：对 0–255 每个 key 解一遍，按 lua-token 密度（`local`/`function`/`return`/`end`）打分，解得出一堆 Lua 的那个就是 key。

3. **un-XOR → 读 Lua 源码里的 flag**。十几行就够：

   ```python
   import re
   d = open("blob4.bin","rb").read()          # 你认出来的那个 XOR blob
   for k in range(256):
       t = bytes(b ^ k for b in d)
       if t.count(b"function") + t.count(b"local") >= 2:   # 解出合法 Lua
           print(hex(k), re.search(rb"FLAG\{[^}]*\}", t).group().decode()); break
   ```

### 二、知识点解析

- Lua 层逆向的**第一刀是认形态**：明文直接读 / 字节码反编译(4.2) / 单字节 XOR 爆破 / 分组加密找 key(4.8)——magic + 可读性 + 熵三件套判。
- 原生 Lua（`\x1bLua`）和 LuaJIT（`\x1bLJ`）是关键分叉，magic 一眼分；unluac 只解原生 Lua，解不了 LuaJIT。
- 真 flag 在被 XOR 加密的脚本里——认对形态 + 脱对加密才拿得到；明文 blob 里那个 flag 是诱饵。
- **排除法定位 XOR blob**：明文（能读，flag 是诱饵）、两个字节码（有 `\x1bLua`/`\x1bLJ` magic，这课读不了）、一个高熵 XXTEA（爆破无效）——剩下那个乱码但**不高熵**的就是单字节 XOR。XOR key 一爆就出：对那个 blob 跑 0–255，哪个 key 解出来满是 `function`/`local`/`end` 就是它，un-XOR 后 `grep FLAG`。
