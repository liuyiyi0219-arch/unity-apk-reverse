# 4.1 作业：认 Lua 形态，脱掉 XOR，读出脚本里的 flag

## 题干

`材料/` 里有 5 个脚本 blob——都是爬塔游戏的 **battle 逻辑脚本**被打进包时的几种落包形态，每个恰好是**一种** Lua 形态。其中一个脚本被加密了，**真 flag 藏在那个被加密的脚本里**——另有一个明文 blob，里面也写着一个 flag，那个是诱饵。把 5 个 blob 各认成一种形态，找出被加密的那个、脱掉加密，读出里面的 flag。

## 材料

下载 `lua-blobs-kit.zip`，里面 `blob1.bin` … `blob5.bin`——爬塔 battle 脚本的 5 种落包形态（自造样本），每个恰好是**一种** Lua 形态。

## 怎么交

读出被加密脚本里那行 `FLAG{...}`，交给批改器：

```bash
check.exe FLAG{...}
```
