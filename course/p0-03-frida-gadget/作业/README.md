# 0.3 作业：备齐 gadget 注入工具链

## 题干

这一课的作业是**把「免 root 焊 gadget」要用的工具备齐**。批改器探你本机的解包 / 签名工具。

你要备齐的清单：

**必需（决定过不过）**
- **apktool**
- **签名工具**（`apksigner` 或 `jarsigner` 任一）

**建议**
- **zipalign**
- **keytool**
- **gadget `.so`（`FRIDA_GADGET`）**

## 怎么交

塔里点节点 → **✍ 做作业** → **▶ 运行环境检查**。必需项全绿 → 点亮过关。
清单里 ✘ 的会写怎么装。整套免 root 注入流程见本章讲义。
