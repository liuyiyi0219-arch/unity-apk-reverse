# 3.5 作业：反推 .fbs → 编成 Python 类 → 用它读数据

## 题干

你有一份 flatc 从**一份你看不到的 `.fbs`** 生成的 C# 读取类（一个邮件消息表 `MailMsg`），还有一段用那份 schema 序列化出来的二进制数据。目标：**把这段二进制正确读出来**。读对了就拿到 flag。

## 材料（`mail-kit.zip`）

| 文件 | 是什么 |
|---|---|
| `MailMsg_generated.cs` | flatc 从一份你看不到的 `.fbs` 生成的 C# 读取类（邮件消息表 `MailMsg`） |
| `mail.bin` | 一段用那份 schema 序列化出来的二进制数据，你最终要能把它读出来 |

## 怎么交

塔里点这个节点 → **✍ 做作业** → 选中你生成的 `MailMsg.py` 上传 → **▶ 运行批改**。

批改器会**用你的 `.py` 去读材料里的 `mail.bin`**，把读出来的 5 个字段和标准值逐一对比：schema 还原对了 → 字段全读对 → 吐 flag 🚩；哪个字段读串了，它告诉你差在哪。
