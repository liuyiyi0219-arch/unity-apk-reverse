# 1.1 作业：在 APK 五层里捡碎片拼 flag

## 题干

这一课的作业不是答题——是**真的在 APK 里走一遍五层**。`材料/starforge.apk` 是一个**五层目录结构桩**：它把 Unity APK 的五层关键目录都摆齐（`classes.dex`、`lib/arm64-v8a/libil2cpp.so`、`global-metadata.dat`、`assets/Scripts/`、`assets/bin/Data/`），每层里各放一个占位小文件当碎片 `_layer_*.txt`。用它走通「五层各取一片」的定位流程——各层文件本身是占位内容，不是能真解包的样本。把五个碎片按层序拼起来，就是这一课的 flag。

## 材料

| 文件 | 是什么 |
|---|---|
| `starforge.apk` | 五层目录结构桩：五层关键目录摆齐，各层文件为占位内容，每层各藏一个碎片文件 `_layer_*.txt` |

## 怎么交

在塔里点这个节点 → **✍ 做作业** → 参数框里填你拼好的 flag → **▶ 运行批改**。
拼对了就点亮；拼错了它会**逐层告诉你哪层的碎片不对 / 顺序错在哪**。
