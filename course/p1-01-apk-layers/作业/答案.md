> 先自己动手，卡住了再看。

### 一、一步步操作

1. 解包 APK（它就是个 zip）：`unzip 材料/starforge.apk -d out`（或改后缀用压缩软件打开）。
2. 进每一层的关键目录，找那层的 `_layer_*.txt`，读出里面的碎片词：

   | 层 | 关键目录 | 碎片文件 |
   |---|---|---|
   | **native** | `lib/<abi>/`（如 `lib/arm64-v8a/`） | `_layer_native.txt` |
   | **C# / il2cpp** | `assets/bin/Data/Managed/Metadata/`（`global-metadata.dat` 所在） | `_layer_csharp.txt` |
   | **脚本** | `assets/Scripts/`（`.luac` 所在） | `_layer_script.txt` |
   | **资源** | `assets/bin/Data/`（`data.unity3d` / AB 所在） | `_layer_resources.txt` |
   | **Java** | 包根（`classes.dex` 旁边） | `_layer_java.txt` |

3. 按 **native → C# → 脚本 → 资源 → Java** 的顺序，把五个碎片词拼进 flag 壳：
   `FLAG{urev-1.1-<native>-<C#>-<脚本>-<资源>-<Java>}`

### 二、知识点解析

- 顺路认一眼每层的「身份证」：`lib/*.so` 是 `\x7fELF`、`global-metadata.dat` 开头是 `AF 1B B1 FA`、`.luac` 是 `\x1bLua`、`data.unity3d` 是 `UnityFS`、`classes.dex` 是 `dex\n035`。碎片藏在哪层、那层放的就是这类东西。
